# College Practical Front Page Generator 📑

A modern, instant, pixel-perfect Front Page Generator for **Manohar Memorial College (MMC), Fatehabad** and other college practical lab files.

Matches the exact dimensions, typography, margins, logo, and layout of the original college practical front pages.

---

## ✨ Features

- 📁 **Smart File Naming**: Automatically names downloaded PDFs and PNGs according to subject and student name:
  - Format: `<Subject>-front-page-<StudentName>.pdf`
  - Examples:
    - `Data-Mining-front-page-SΛNΛM .pdf`
    - `Computer-Graphics-front-page-Anand.pdf`
    - `Linux-front-page-SNM.pdf`
- 📄 **Print-Ready Vector & 300 DPI Export**:
  - **Download PDF**: Direct 1-click A4 PDF download.
  - **Download PNG**: High-resolution 300 DPI image.
  - **Print / Save**: Direct browser print dialog with `@page` borderless A4 setup.
  - **Copy Image**: 1-click copy to clipboard to paste directly into MS Word.
- 🏛️ **College Customization**:
  - Official MMC Logo + *Estd. 1970* embedded with transparency.
  - Option to upload a custom logo or change college name/city for other institutions.
- 💾 **Local Auto-Save**: Automatically remembers student name, class, roll number, and last used subject in `localStorage`.



## 💻 Running Locally

You can run this project locally in any of the following ways:

1. **Directly in Browser**: Just double-click `index.html` to open it in Chrome, Edge, or Firefox.
2. **Via Python local server**:
   ```bash
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.
